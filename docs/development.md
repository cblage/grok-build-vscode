# Development

Build, test and repo conventions for people working *on* this extension. If you
are here to *use* it, [README.md](../README.md) is the right page.

## Build and test

```bash
npm install
npm test                  # grok-free unit/DOM/fake-CLI suite
npm run test:integration  # real VS Code Extension Host smoke (also required by CI)
npm run test:desktop      # real Electron window + fake CLI (desktop host)
npm run e2e:screens       # real Electron, real layout — leaves frames in .screens/
npm run package           # → grok-vscode-phuryn-<version>.vsix (marketplace README only)
npm run desktop           # run Desktop from the compile tree
npm run dist:win          # Windows x64 installer → dist-desktop/
npm run dist:mac          # macOS arm64 + x64 (must run on macOS)
```

`npm test` is grok-free and never spawns the real binary. CI also requires the
separate `npm run test:integration` Electron smoke. An on-demand
`npm run test:live` drives the actual `grok` end-to-end (handshake, restore,
native plan verdicts, image/video gen) and is run **before a release**, not on
every commit.

`npm run e2e:screens` exists because the DOM suites run in happy-dom, which has
no layout engine: rects are zeros and stylesheets never apply, so an icon with
no size or a control pushed off-screen satisfies every assertion those suites
can make. Anything about *painted geometry* belongs there instead.

## The two READMEs

The Marketplace / Open VSX description is **[README.marketplace.md](../README.marketplace.md)**
(extension only), generated by `scripts/gen-marketplace-readme.cjs` from
`README.md`. `npm run package` always passes `--readme-path README.marketplace.md`
so the GitHub dual-host README cannot ship as the store listing by accident.

The generator drops this section from the listing by name, so contributor
material under `## Development` in `README.md` never reaches the store page.

## Repo conventions

- Direct-to-`main`, no feature branches.
- Commits explain the *why*, not the *what*.
- No speculative abstractions.
- The grok-free suite is the floor — every change keeps it green.
